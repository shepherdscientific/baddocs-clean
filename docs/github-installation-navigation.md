# GitHub Installation and Navigation

## Installation

Install BadDocs directly from GitHub:

```bash
pip install git+https://github.com/shepherdscientific/baddocs.git
```

## Repository Navigation

- `src/` - Main source code
- `tests/` - Test suite
- `config/` - Configuration files
- `scripts/` - Utility scripts
- `docs/` - Documentation
- `github-action/` - GitHub Action
