# BadDocs

BadDocs is an AI-powered documentation generation and analysis framework designed to help understand and document complex codebases.

## Features

- **Multi-language Support**: Support for Python, Java, JavaScript, Go, Rust, C#, PHP, Ruby, R, COBOL, VB6, PowerBuilder, Fortran, and more
- **Database Analysis**: Analyze and document database schemas, relationships, and procedures
- **Incremental Processing**: Efficient incremental analysis with caching
- **AI-Powered Documentation**: Generate documentation using state-of-the-art LLMs
- **Web Interface**: User-friendly web interface for browsing and managing documentation
- **GitHub Integration**: Seamless integration with GitHub repositories
- **MCP Support**: Model Context Protocol server for AI integration

## Installation

```bash
pip install -e .
```

## Quick Start

```bash
baddocs init
baddocs generate --path /path/to/repository
```
